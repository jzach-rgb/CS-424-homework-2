This project explores Cor Coffee's sales data to understand customer drink preferences, modifier selections,
and purchasing patterns throughout the day. The dataset was cleaned and processed using Python and Pandas, with 
visualizations created using Matplotlib. Three visualization approaches were developed, including a stacked bar chart, heatmap, 
and line chart. The heatmap was selected for further refinement to better compare oat milk preferences across different drinks and time periods.
The repository contains the original and processed datasets, Python scripts, visualizations, and a report documenting Tasks 1–7.
